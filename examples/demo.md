# 为什么要用代码生成视频

传统的视频制作流程很长：写脚本、找素材、剪辑、配音、加字幕，每个环节都
需要专门的人。对于知识类内容，真正有价值的是观点和逻辑，而不是炫酷的转场。

## 代码生成视频的核心思路

把视频看成一段**可执行的结构**，而不是一帧帧手工拼出来的画面。你描述"讲
什么"和"怎么讲"，由程序负责排版、动画与合成。

这种方式有三个好处。第一，内容与形式分离，改文字就能重出片。第二，风格统
一，不会因为手工操作而前后不一致。第三，可以被版本管理，像代码一样迭代。

## 一条流水线的六个阶段

整条链路是：文章 → 口播稿 → 分镜 → 配音 → 时长对齐 → 渲染合成。每一步都
是清晰的输入输出，任一步出错都能定位。

旁白是整条流水线的主时钟：每个镜头的时长由它的配音决定，画面去适配声音，
而不是反过来。

## 小结

当内容足够结构化时，用代码生成视频不仅更快，而且更稳定、更可复现。
